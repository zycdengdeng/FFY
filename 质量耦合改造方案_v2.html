一、诊断:三处独立缺陷

# 缺陷 位置 后果
B1 每个力都写成 m 的正比量(k=κmgL、kc=4000mg、杆件质量=5%m) models.bird_size_x a=F/m 中 m 约掉 ⇒ 归一化响应严格不变

二、修法

P1 · 物理去归一化(改 3 处,是全部改动的核心)

P1.1 接触改为绝对介质属性,并升为工况维

F_contact(δ, δ̇) = k_c·δ + c_c·δ̇ + ½·ρC_dA·δ̇²        (δ>0)
  • k_c [N/m]、c_c [N·s/m]、ρC_dA [kg/m] 全部绝对单位,与 m 无关
  • 硬地:k_c≈2e6,拖曳项=0;软地/湿滩:k_c≈1e4–1e5;水面着陆:k_c 小 + 拖曳项主导
  • 一举三得:(a) 破坏不变性;(b) 修好 B3,E13 的 ±30% 变成真正的"地形/介质变化";
    (c) 把课题真正的场景(水鸟着水)纳入模型,而不是只做硬地落震

为什么 m 就活了:接触频率 ω_c=√(k_c/m) ∝ m^(-1/2),而腿的频率 ω_leg=√(κg/L_leg) 与 m 无关。
两者之比在 m: 1→12 kg 上变化 3.46 倍。软端更狠:静沉陷 δ=mg/k_c,k_c=1e4 时 1 kg 沉 1 mm、
12 kg 沉 12 mm——而 s_max 只有 8–40 mm。重机器在软地上要先赔掉一半行程预算。

P1.2 杆件质量由结构定尺导出,不再是 5%·m

复用 e8_struct.py 的链条(关节力矩 → 薄壁管 t=0.1D → 弯曲+轴向应力 + 欧拉屈曲,SF=2):

弯曲控制:  D ∝ (m·L)^(1/3)          杆质量 ∝ ρ·L·D² ∝ m^(2/3)·L^(5/3)
屈曲控制:  D ∝ (m·L²)^(1/4)

配合 L ∝ m^0.39,腿质量分数 ∝ m^0.32(1→12 kg 增长 2.2 倍)——这就是平方立方律。

实施细节:一次仿真 → 关节力矩 → 定尺 → 可行性 + 导出质量。是否需要第二遍
(新质量回代再仿真)用 200 个设计的抽样实测决定;若二次迭代对 peak_a 的影响 < 1%,
就只做一遍并把残差写进报告。不假设,实测。

P1.3 结构判据上线成在线可行性

v1 里应力/屈曲只是事后分析(E8),v2 里进入可行性门:

可行 ⇔ peak_a ≤ g_cap  ∧  stroke ≤ s_max  ∧  回弹比 ≤ 5%
       ∧ σ_max ≤ σ_y/2  ∧  P_axial ≤ P_euler/2  ∧  F_peak ≤ F_max

σ_y、E、F_max 全是绝对量,不随 m 缩放 ⇒ 可行域随 m 单调收缩。这是最干净的质量依赖。

P1.4 保持不变的部分(重要)

κ = k/(m·g·L_leg)、ζ、r2、r3 继续用无量纲形式。它们是良构的无量纲群,
换成绝对单位只会让 1 kg 与 12 kg 的取值范围失配,那是把问题搞坏而不是搞对。
不变性由 P1.1–P1.3 的绝对量打破,这才是物理上正确的破缺路径。

P2 · 生物先验条件化 p(x|m)

把几何三维改成相对生物学基线的 z 分数,网络的盒子因此保持固定且与 m 无关:

log L1 = a + b·log m + σ_L·u_L          u_L ∈ [-2, +2]
r2     = r̄2(m) + σ_2·u_2                u_2 ∈ [-2, +2]
r3     = r̄3(m) + σ_3·u_3                u_3 ∈ [-2, +2]
  • (a, b, σ_L) 由 AVONET 214 种水鸟拟合,现有值 b = 0.39 ± 0.03
  • r̄2/r̄3 先检验 Watanabe 91 种里是否存在质量趋势;无趋势就退化为常数(即 v1 的边缘盒)
  • 网络输入 x_net = (u_L, u_2, u_3, κ_踝, κ_膝, κ_髋, ζ),全部与 m 无关 ⇒ cVAE 结构一行不用改
  • 数据工厂改动:先采 (m, v0, 介质),再采 u,最后用 m 展开成物理 x。约 5 行

P3 · 消融升级:从"选盒子"改成"选标度指数"

v1 的 bio/wide/shift 三盒消融最大的软肋是"你是不是挑了个不好的 shift 盒"。
v2 里三臂退化成同一个 b 的四个取值,每一个都是文献里有名有姓的零假设:

臂 b 出处 含义
bio 0.39 AVONET 实测 水鸟腿的正向异速生长
geo 1/3 几何相似 等比例放大
elastic 1/4 McMahon 弹性相似 抗屈曲优先
none 0 = v1 的边缘盒 无尺度知识

四臂盒子体积、形状、位置全部由同一公式生成,只差一个标量 ⇒ "精挑细选"的质疑自动消失。
而且这个消融现在回答的是一个真问题:AI 该不该继承生物的标度律?

六、判断:采纳,顺序不变

Codex 的核心判断正确且必须执行:先修物理,再埋路径。补充一条更强的理由——
在 v1 物理上做质量 walk 不只是"得到一条平线没用",而是有害:
若再加 path-consistency 损失,等于用损失函数显式地把 ∂x/∂m = 0 这个人为假象钉死。
这比"白跑"严重。

6.1 v1 里已经做对的一件事

Codex 建议区分 c_phys=(m, v0, 介质) 与 r=(g_cap, s_max, η_min),并指出改 r 不必重仿真。
这在 v1 中已经是既定设计:data_factory.py 只扫 (m, v0)×设计并存全部指标,
g_cap/s_max 在 build_dataset.py 构训练对时才抽签。

由此得到一个零成本的机会:要求空间的路径可以从冻结的 v1 池里直接造,一次仿真都不用跑。
配合 v0 在 v1 物理里本来就是活维,于是——

可以在 v1 冻结池上先把整套 path 机制跑通:数据格式、按束切分、path 损失、
防泄漏评测。这件事零算力、零墙钟(我写 v2 代码时机器本来空着),
而且能在建 v2 之前就回答"同等仿真预算下,path 数据是否真的强于独立 LHS"。

如果答案是否,我们就不必建 V2-PathLoss,省下的是数天。这是这轮讨论里 ROI 最高的一步。

七、路径协议(两遍,不是一遍)

Codex 的 60/25/15 有一处结构性问题:边界加密无法与前两者同批产出——
它需要先有可行性模型才知道边界在哪。所以必须分两遍:

遍 内容 仿真量 占比
① 全局块:375 工况 × 120 设计 45,000 63%
① 路径束:25 束 × 120 锚点 × 5 工况 15,000 21%
② 边界加密:用 ① 训出的 FeasNet 定位 p_feas≈0.5 等值面,附近 100 工况 × 120 设计 12,000 17%
合计 72,000 (v1 为 60,000,+20%)

路径束的构成(每束 = 同一批 120 个锚点设计,沿一条工况线走 5 步):

束型 数量 走法 用途
v0 10 v0: 0.6→1.6,Δ=0.25 最强动力学效应,边界穿越最清楚
m_allo 6 固定 u_L 走 m,L1 按 exp(a+b·log m+σu_L) 同步变 保持异速生长的工况路径:追踪"同一形态型"随体重的演化
m_iso 4 固定绝对 x 走 m 反事实对照:纯物理的质量效应
medium 5 k_c: 1e4→2e6 对数等距 硬地↔软地↔水面

m_allo 与 m_iso 成对存在,是因为它们直接给出一个分解:

dy/dm |_allo  =  ∂y/∂m |_x        +      (∂y/∂x)·(dx/dm)|_bio
   (总效应)      (m_iso:纯物理)         (差值:生物先验的贡献)

这个分解本身就是结果,不只是训练数据——它量化"生物的标度律在多大程度上补偿了体重增长"。

八、把 m_allo 从采样技巧升级成主实验

Codex 把 allometry-preserving path 当作更合理的采样方式。我认为它应该是主图:

沿 m_allo 路径把 m 一直推到可行性失效,得到

m*(u_L, b) = 某个形态型仍能在 g_cap 内着陆的最大体重

这是一条尺度极限曲线。结合 §二 P3 的 b 指数消融,直接提出一个可证伪的问题:

实测的生物标度指数 b = 0.39 是否使可行体重范围最大?

  • 若是 → "生物的标度律对着陆任务近乎最优",强结论
  • 若否 → "生物在为别的功能(涉水、觅食)优化,着陆不是主约束",同样是结论

无论哪个方向都是结果,且正好是博士方向那句话的实体化:
可行域与性能边界如何随生物尺度与工程工况连续演化。

九、对 Codex 另外两条建议的修正

9.1 三头架构(F 性能 / C 可行 / G 生成):采纳分解,拒绝共享主干

理由是项目特有的:

  1. C 已经存在且很好(E12 FeasNet,AUC 0.9991),不需要重新接线。
  2. E5 循环里刻意没有代理模型——真值裁判是 Exudyn。"零在线仿真下比 BO 好 6 倍"
    是这条线最干净的卖点;挂一个共享主干的性能头 F,评审很容易读成
    "又变回代理模型优化了",而且引入 F↔G 的训练耦合,又多一个要消融的东西。
  3. Codex 自己的规矩是"别一次同时改物理/先验/采样/架构/损失"——共享主干就是架构改动,
    按他自己的规矩,V2-Base 里不该有。

→ 三个独立模型共用同一个池子,不共享编码器。共享主干推迟到 V2.5,且以 path 数据先证明有效为前提。

9.2 消融阶梯:V1-Frozen 不是一个臂

名称 是否可与其它臂同表比较
V1-Frozen ❌ 物理不同,只能作叙事参照("我们修了什么"),数字不能进同一张表
V2-Base ✅ 修正物理 + p_bio(x|m),普通 LHS + cVAE
V2-PathData ✅ 同物理,路径样本当普通样本用,同仿真预算

9.3 切分纪律:具体会炸在哪里

Codex 的"整条路径必须整体进训练或测试"是对的。我们这里的具体炸点是:
E5 的"防考题泄露"防线按 cid(工况编号) 切分,而一个路径束把同一批设计放进 K 个不同 cid。
按 cid 切 ⇒ 同一个设计同时出现在训练与测试侧 ⇒ 静默泄漏。

→ 切分单元必须从 cid 改成 bundle_id;非路径块的 bundle_id = 自身 cid。改动约 10 行,
但不改就会得到一个虚高且很难自己发现的数字。

十、与 GeoPT(Wu et al., ICML 2026)的关系

课题组另一条线在读的 GeoPT 与本项目方向相反但共用同一条理论,值得在论文里引一次:

GeoPT 本项目
什么便宜 几何(web 规模现成模型) 物理(Exudyn 约 1 s/次)
什么贵 物理标签(单样本 6.1×10⁴ CPU·小时) 生物几何(214 种,不可增)
做法 合成动力学 v~Unif(B),把 G 提升到 (G, V) 合成几何:用拟合的标度律把 214 个离散 (m_i, x_i) 提升成连续流形 x(m, u)
尺度 1.6 亿网格,Transformer 主干 7 维标量,小 MLP

共用的理论是它的 Remark 4.2:

slice( E_V [ F_lifted(x; G, V) ] ) = F_native(x; G)

即:只在原生空间预训练,学到的是沿被忽略维度取期望的那个塌缩表示,信息有损。

这正是 v1 的病理的精确描述:因为响应流形沿 m 是平的,我们的 cVAE 学到的是 E_m[·]——
一个沿质量维塌缩的表示。GeoPT 因此给了我们两样东西:

  1. 给自己的 bug 一个可引用的名字(degenerate / reduced representation,沿无监督信号的条件维塌缩);
  2. 给 condition-path 一个可引用的理由:i.i.d. 的 (x_i, c_i) 只能学到 c 的切片期望,
    同一 x 在多个 c 上的配对才监督"张成的流形"而非"切片"。

另外可引用其负迁移结论(只用几何预训练反而变差)来加固 E11 的立论:
先验加在错误的轴上会有害——这正是我们的消融要测的。

不应借鉴的是它的规模与架构。7 维问题 + 秒级求解器,与 1.6 亿网格 + 6 万 CPU·小时是两个世界;
"把 GeoPT 搬到起落架上"是错的表述,"两者是同一枚硬币的两面"才是。

二、通道归因:哪一处改动在起作用

把 v2 的改动逐个退回 v1 写法(turf 地形):

组合 k_c 杆件质量 接触阻尼 peak_a 沿 m 相对极差
A 全 v1 口径 4000mg 5%·m 0.01k_c 0.00%
B 接触(刚度+阻尼) 绝对 5%·m 2ζ√(k_c m) 76.9%
B2 只绝对化刚度 绝对 5%·m 0.01k_c 96.1%
C 只改杆件质量 4000mg 定尺导出 0.01k_c 0.38%
D 全 v2 绝对 定尺导出 2ζ√(k_c m) 77.8%

三条读数:

  1. A 组精确复现 0.00% —— 独立于 E14 再次确认 v1 的不变性,同时证明 v2 代码没有
    引入无关改动(退回 v1 参数就得到 v1 结果)。这是最好的回归测试。
  2. 质量效应几乎全部来自接触的绝对化。这符合物理:地面刚度是地形属性,
    v1 把它写成 4000·m·g 等于假定"地面对更重的机体更硬",这是全部人为不变性的主源。
  3. 杆件质量导出对动力学几乎无贡献(0.38%)——因为腿只占机体质量 0.2–4%。
    但它不是白改:它的作用在可行域而不在响应(见 §一 的 slenderness 换手)。
    论文里要把这句话说清楚,否则会被问"既然只有 0.38%,为什么要改"。

三、实测确定的几个工程细节

  • 两遍质量回代必须做:第二遍对 peak_a 的影响中位 2.2%、P90 4.1%、最大 33.6%。
    代价是仿真量翻倍,但 33.6% 的尾巴不能忽略。
  • 腿质量分数:中位 0.88%,范围 0.22–3.96%,与 E8 独立得到的 0.5–1.5% 一致。
  • 软端有模型上限:k_c=1.2e4(泥)时 m≥4 kg 全部失败——动态侵入深度超过足端球
    半径 8 mm,球-面罚接触模型本身失效,不是物理。因此 KC_RANGE 收窄到
    [3e4, 2e6](湿沙→混凝土,约 2 个数量级)。泥/水这类大侵入介质需要
    v²拖曳+附加质量的入水模型,列为 v2.1,不阻塞主线。
  • 几何上限是关键:D ≤ 0.25×段长。没有这条,应力和屈曲永远可以靠把管加粗化解,
    平方立方律根本咬不到人。加上之后高质量端才会出现 slenderness 失效。

修法:加足端传感器,把两者分开——

量 含义 用途
stroke 机体总下沉 报告
sink 地面下陷(足球心低于半径的部分) 报告 + 模型有效性判据
leg_stroke = stroke − sink 起落架自身行程 塌陷判据与 s_max 都改用它

同时把"模型失效"与"物理不可行"彻底分家:fail="deep_sink"(侵入 > 0.9×足端半径,
罚接触模型出界)vs fail="collapse"(扣除下陷后腿仍被压塌,是设计不行)。

一、更正:"高质量端平方立方律接管"是检查顺序的伪影

实施记录 ③ 里我写:turf 上 slenderness 失效从 m=1 的 0 涨到 m=12 的 67,结论是
"平方立方律接管了设计问题"。这个结论不成立,现予撤回。

原因:feasible_v2 当时只报第一个违反的判据,顺序是 g_cap → s_max → slenderness。
低质量端峰值高、g_cap 先失效,把这些设计的结构状态整个遮住;高质量端峰值低、
过了 g_cap,才轮得到结构判据被检查。看上去的"换手",一半是遮蔽解除。

pilot 的 10,200 次仿真里独立评估结构判据(不看检查顺序):

质量档 n slenderness 失效率
1–2 kg 3109 61.3%
2–4 kg 2812 59.7%
4–8 kg 2799 55.6%
8–12 kg 1428 50.2%

是轻微下降,不是上升。 机制上说得通,而且比原来的说法更有意思:

平方立方律      载荷 ∝ m,截面 ∝ L² ∝ m^0.78  ⇒ 管径需求相对变粗   ← 不利
质量-地面耦合  绝对地面对重机体相对更软,峰值降 51%(24.7→12.0 g) ⇒ 载荷少涨   ← 有利
                                                        两者几乎抵消,净剩 6% 有利

两个质量通道在结构判据上互相抵消。 这是新结论,也是能力图那张脊的结构侧对应物。

代码已修:feasible_v2 改为返回全部违反项而非第一个,统计不再带顺序伪影。

四、还有一条不能忽视的物理下限 

v0 = 1.2 m/s,腿行程 8.4 mm(中位) → a = v²/(2s) = 8.7 g
要压到 5 g,需要行程 14.7 mm

峰值是被行程卡住的,不是被地面卡住的。 而行程又受制于 κ 的下限——
κ = k/(m·g·L_leg) 是簧扭矩比重力扭矩,κ 太小腿撑不住自重。
所以"把腿调软到任意程度"在物理上不成立,这是设计空间的硬边界,应写进论文。

    (bio 停 0.25、geo 0.22、elastic 0.20、none 0.08——平衡点仍随先验排序)。
  • 按 g_cap 紧(4–8g)/松(18–25g)分层:四臂的 b_eff 分层差均 <0.01——
    物理偏好的斜率对要求强度不敏感,是接触/结构物理的性质,不是约束抽签的伪影。

E18 · 可行体重走廊(kc=1e5, gcap=10g, smax=24mm)

b=0 的走廊在重端塌掉,b>0 的三臂顶到扫描上限:

臂 b 走廊上限 m_hi(随 u) 概括

机理直白:盒子不随体重长,重机器要的长腿(60 kg 按异速律 ≈190 mm)在 none 的

三条证据链的合流(汇报叙事定稿)

  1. E17(生成侧):工况段内部,物理只温和偏好更平的斜率,各臂停在按先验排序的
    平衡位(0.27/0.25/0.22/0.10);u 无贴墙 → 先验不是表达瓶颈,是到达瓶颈。
  2. E18(可行性侧):走出工况段,b=0 在重端塌方,b>0 都活着 → 尺度先验的
    价值在边界与外推,不在中央    。
  3. E19(绝对成绩侧):整个工况分布合起来考,bio 的生成器总分第一,排序随 b 单调
    → none 的 b_eff=0.10 不足以跨体重跟踪(它的表达上限 0.363 够,但 20 轮学习
    只把它推到 0.10)——先验的作用 = 把起点放到物理温和拉力够得着最优的位置。

一句话:平顶山中央,谁站哪儿无所谓;但把整场比赛(全工况+边界)算总分,
从生物侧上山的队伍赢了——不是因为生物先验点对了,而是它离"够得着"最近。
